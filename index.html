検出条件について
  • 新着開示シグナル — 上場企業がEDINETに提出した報告書の本文を毎朝読み、 「減損損失 / 閉鎖 / 統廃合 / 本社移転 / 遊休 / 撤退 / リースバック / 固定資産の譲渡・売却 / 構造改革 / 事業再編 / 資本効率」の出現回数を数えて多い順に表示します。 投資信託・ファンド関連の開示は除外しています。
  • 含み益 — 有価証券報告書の「賃貸等不動産」注記にある 時価 − 帳簿価額。開示している約2,000社が対象で、不動産業(プロの保有者)は除外しています。
  • 調査は無料APIの範囲で毎朝自動で進み、対象企業(約3,800社)を約40日で一巡します。
  • 数値は機械抽出の概算です。商談前に必ず原典(EDINETの開示書類)を確認してください。
出典: EDINET(金融庁) / EDINET DB — データは毎朝8:00に自動更新されます。
