CRE Scout.

上場企業の不動産売却シグナルを、公開情報から毎朝自動発掘

このリストの選出基準

基準1: 開示シグナル

EDINETに提出された有価証券報告書・臨時報告書の本文から、売却の予兆となる13語 (減損損失 / 閉鎖 / 統廃合 / 拠点統合 / 本社移転 / 遊休 / 撤退 / リースバック / 固定資産の譲渡・売却 / 構造改革 / 事業再編 / 資本効率)の出現を検出。 直近2週間・投資信託等は除外。

基準2: 含み益

有価証券報告書「賃貸等不動産」注記の時価 − 帳簿価額。 開示している約2,000社が対象(不動産業=プロの保有者は除外)。 全上場企業 約3,800社を毎朝約90社ずつ自動調査。

並び順

① 基準1と2の両方が揃う企業(青バッジ) → ② シグナル検出企業(出現回数順) → ③ 含み益上位企業。シグナル検出企業は不動産データを優先調査します。

出典: EDINET(金融庁) / EDINET DB(edinetdb.jp) — 毎朝8:00に自動更新。 数値は機械抽出の概算のため、商談前に必ず原典(EDINETの開示書類)をご確認ください。

発掘リスト

開示シグナル(直近2週間)と含み益データを企業ごとに統合。両方が揃う企業ほど上位に表示します。
