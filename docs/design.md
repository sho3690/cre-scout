# CRE Scout — 企業不動産売却 案件発掘・管理システム 設計書(MVP)

日付: 2026-07-29 / 対象: 企業不動産売却コンサル事業の構成システム(ユーザー提供仕様書)のMVP

## 1. 目的とスコープ

仕様書の中核は「企業の経営課題から売却案件を能動的に発掘する」こと。MVPは仕様書
§13の「3つの営業ツール」をそのままデジタル化し、日々の営業運用が回る最小構成とする。

**MVPに含む**
1. **企業スコアリング台帳**(§6/§13-②) — 企業CRUD、100点スコアリング(35/25/20/10/10)、
   売却シグナルチェックリスト(§4)、保有不動産と含み益、商談ステージ、期待収益の自動計算
2. **1枚CRE診断書**(§7/§13-③) — 台帳データから自動下書き生成 → 編集 → A4印刷(PDF保存)
3. **営業対象基準**(§5/§13-①) — 対象基準・配点・シグナル・手数料早見・コンプラ(§12)の参照タブ
4. **ダッシュボード** — KPIファネル(§11)、優先度分布、重点企業、次回アクション
5. **データ管理** — JSONバックアップ/復元、CSVエクスポート、サンプルデータ

**MVPに含まない(Phase 2候補)**
- EDINET/TDnet APIによる開示情報の自動監視・キーワード検知(§2/§4) — APIキー取得と
  定期実行基盤が必要。MVPではシグナルを手動チェックで代替
- 複数人同時利用・サーバーDB・買主候補マッチング

## 2. 方式比較と採用案

| 案 | 内容 | 評価 |
|---|---|---|
| **A. 単一HTML + localStorage(採用)** | ダブルクリックで起動。データはブラウザ内のみ | セットアップ不要・オフライン・機密が外部に出ない。単一端末利用がMVPの実態に合う |
| B. ローカルWebアプリ(Node+SQLite) | サーバー起動が必要 | EDINET自動化を入れるPhase 2で移行先候補 |
| C. Notion/スプレッドシート運用 | ノーコード | スコア自動計算・診断書生成・ファネル可視化が困難 |

## 3. 画面構成

タブ5つ: ダッシュボード / 企業台帳 / CRE診断書 / 営業基準 / データ管理。
台帳はリスト⇔編集フォームの2段階。ライト/ダークテーマ対応。

## 4. データモデル(localStorage `creScout.v1`)

```
company: {
  id, name, listing(上場|非上場), industry, region, url, memo, sample?,
  fin: { totalAssets(百万円), reBook(百万円), debtNote },
  properties: [{ type, location, area, book(百万円), est(百万円), note }],
  signals: [signalKey...],
  score: { needs≤35, value≤25, access≤20, timing≤10, profit≤10 },
  deal: { stage, prob(%), type(仲介|買取|未定), price(百万円), buyMargin(百万円),
          nextAction, nextDate },
  diag: { challenge, effect, recommend, reason, materials, next30 },
  createdAt, updatedAt
}
```

**自動計算**(仕様書の式のまま)
- 仲介手数料 = 税抜価格 × 3% + 6万円(片側・400万円超) → §9の例(5億→1,506万円)と一致検証済
- 不動産比率 = 不動産簿価 ÷ 総資産
- 含み益仮説 = Σ(想定時価 − 簿価)
- 期待収益 = 成約確率 × (仲介手数料 or 買取粗利)
- 優先度 = スコア70+:A重点 / 50–69:B継続 / 49-:C様子見(§6「70点以上を重点」)

**ステージ**(§11 KPIファネルと同一): 候補 → 接触中 → 初回面談 → NDA締結 → 査定・提案
→ 媒介契約 → LOI → 成約(+中止・見送り)。ファネルは「当該ステージ以上に到達した社数」。

## 5. 技術・デザイン

- 素のHTML/CSS/JS。外部通信ゼロ(オフライン動作、機密データはブラウザ外に出ない)
- チャートは evilcharts デザイン言語(ECharts v6 同梱、約1.1MB)
- ページデザインは ~/.claude/design-system.md(落ち着いた青アクセント・公共サービス品質)
- ユーザー入力は全てエスケープして描画(XSS対策)。金額入力は百万円単位+億円換算表示
- 上場企業編集時にインサイダー情報注意(§12)を常設表示
- 診断書は @media print でA4整形 → ブラウザの「PDFとして保存」

## 6. エラー・保険

- 全データはJSONで書き出し/復元可能(端末変更・誤削除への保険)
- 削除系は確認モーダル必須。ネイティブconfirm/alertは使わない
- 初回起動時は架空のサンプル企業8社を投入(実在企業とは無関係と明記、一括削除可)
