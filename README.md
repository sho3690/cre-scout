# CRE Scout — 企業不動産 売却シグナル発掘ツール

上場企業の「不動産を売りたくなっているサイン」を、公開情報から毎朝自動で見つけるツールです。

**公開サイト: https://sho3690.github.io/cre-scout/**

## 何ができるか

| 機能 | 内容 |
|---|---|
| 新着開示シグナル | 前日までにEDINETへ提出された有報・臨時報告書の本文から「減損損失」「閉鎖」「リースバック」等を検出し、多い順に表示(直近2週間) |
| 含み益ランキング | 有報の「賃貸等不動産」注記から **時価−簿価(含み益)** を抽出し、事業会社(不動産業を除く)の上位を表示 |
| 候補リスト | 気になる企業を「リストに追加」→ **CSVコピー/ダウンロード** して、お使いの管理ツール(スプレッドシート・CRM等)へ |

案件管理・スコアリング等の管理機能は持ちません(別ツールで行う前提)。
旧フル機能版(台帳・CRE診断書つき)は `legacy.html` に残してあります。

## データの自動更新

GitHub Actions が**毎朝8:00(日本時間)**に自動実行します(`.github/workflows/daily-scan.yml`)。
Macの電源が入っていなくても動きます。

1. `tools/edinetdb_scan.py --screen` — EDINET DB(無料枠100回/日)で全上場企業(約3,800社)を約90社/日ずつ調査 → 含み益ランキング更新
2. `tools/edinet_check.py --days 2` — 公式EDINET APIで新着開示の本文を検査 → シグナル更新
3. 結果(`data/*.js`)をコミット → サイトに自動反映

- APIキーはリポジトリの **Secrets** にのみ保存(EDINETDB_API_KEY / EDINET_FSA_KEY)
- 止めたいとき: GitHub → Actions → daily-scan → Disable workflow
- 手元で今すぐ動かす: `EDINETチェック.command` をダブルクリック
- 企業を指定して深掘り: `python3 tools/edinetdb_scan.py --company 企業名`

## 検出条件(要約)

- **シグナルキーワード**: 減損損失 / 閉鎖 / 統廃合 / 拠点統合 / 本社移転 / 遊休 / 撤退 /
  リースバック / 固定資産の譲渡・売却 / 構造改革 / 事業再編 / 資本効率
  (投資信託・ファンド関連の開示は除外)
- **含み益** = 賃貸等不動産注記の 時価 − 帳簿価額(開示企業 約2,000社が対象)

## 注意

- 数値は有価証券報告書からの**機械抽出の概算**です。商談前に必ず原典を確認してください。
- 上場企業の未公表情報は扱っていません(公開開示のみ)。商談化の際はインサイダー情報の取扱いに注意。
- 出典: EDINET(金融庁)/ EDINET DB(edinetdb.jp)

## ファイル構成

- `index.html` — 発掘ツール本体(約22KB・単一ファイル)
- `legacy.html` — 旧フル機能版(台帳・スコアリング・CRE診断書・ダッシュボード)
- `tools/` — 調査スクリプト2本(Python・標準ライブラリのみ)
- `data/` — 自動更新される表示用データ
- `docs/design.md` — 当初の設計記録
