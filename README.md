# CRE Scout — 企業不動産 案件発掘・管理(MVP)

企業不動産売却コンサル事業の「3つの営業ツール」をデジタル化した、1ファイルで動くアプリです。

## 使い方

`index.html` を**ダブルクリック**するだけで、ブラウザで動きます。
サーバーもインストールも不要で、インターネット接続がなくても動作します。

初回はサンプル企業9社(架空・実在の企業とは無関係)が入っています。
画面の動きを確認したら「データ管理 → サンプルだけ削除する」で消して、本番利用を始めてください。

## 画面の構成

| タブ | 内容 |
|---|---|
| ダッシュボード | KPIファネル・優先度分布・次回アクション・スコア上位 |
| 企業台帳 | 企業の登録・100点スコアリング・売却シグナル・商談ステージ管理 |
| CRE診断書 | 台帳データからA4の1枚診断書を自動生成 → 手直し → 印刷(PDF保存) |
| 営業基準 | 対象基準・配点・監視キーワード・手数料早見・コンプライアンスの参照 |
| データ管理 | JSONバックアップ/復元・CSV書き出し・サンプル操作・全削除 |

## 自動計算(入力すると勝手に計算されます)

- **片側仲介手数料** = 税抜価格 × 3% + 6万円(5億円 → 1,506万円)
- **不動産比率** = 土地・建物簿価 ÷ 総資産
- **含み益仮説** = 想定時価 − 簿価
- **期待収益** = 成約確率 × (仲介手数料 or 買取粗利)
- **優先度** = スコア70点以上: A重点 / 50〜69: B継続 / 49以下: C様子見

金額の入力は**百万円単位**です(入力欄の下に億円換算が表示されます)。

## 大事な注意

- **データはこのブラウザの中だけに保存されます。** ブラウザの「閲覧履歴・サイトデータの削除」をすると消えるため、
  「データ管理 → JSONで書き出す」で**定期的にバックアップ**してください。
- 企業の機微情報を扱うため、**共有PCでの利用は避けてください**。
- 上場企業の未公表の売却検討情報は**インサイダー情報**に該当する可能性があります(台帳画面にも注意書きが出ます)。
- 診断書の数値は概算です。正式な査定・税務判断は現地調査と専門家確認の後に。

## 次にやること(やさしい版)

むずかしい言葉ぬきで、順番にやることリストです。

1. **ひらく** — `index.html` をダブルクリック。それだけでアプリが開きます。
2. **さわってみる** — 最初から入っている9社は「練習用のニセモノ会社」です。
   ボタンを押したりこわしたりしても大丈夫。何をしても本物のデータは傷つきません。
3. **練習用データを消す** — 慣れたら「データ管理」→「サンプルだけ削除する」。
4. **本物の会社を10社入れる** — 「企業台帳」→「企業を登録」。
   全部うめなくてOK。まずは会社の名前だけでも入れれば台帳になります。
5. **点数をつける** — 会社ごとに「売りたそう度」などの点数を入れます。
   合計70点以上になった会社が「先に会いに行く会社」です(アプリが自動で教えてくれます)。
6. **1位の会社の診断書を作る** — 「CRE診断書」タブを開くと文章が自動で出てきます。
   気になるところだけ直して「印刷・PDF保存」。これが会社に持っていく資料です。
7. **週に1回、2つだけやる** — ①「データ管理」→「JSONで書き出す」でお守り(バックアップ)を保存。
   ②会った会社の「ステージ」と「次回アクション」を書きかえる。
8. **ときどき「発掘」タブを見る** — 毎日8:00に自動調査が動いてランキングが育つので、
   気になる会社があったら「台帳に追加」ボタンを押すだけです(クリック作業は不要になりました)。

これをくり返すだけで、ダッシュボードに「今どこまで進んでいるか」が自動でたまっていきます。

## EDINET連携ツール(Phase 2・導入済み)

`tools/` に2つの調査ツールがあります。APIキーは `tools/edinet_key.txt` に保存(公開厳禁)。

### ① EDINET DB スキャナ(毎日8:00に自動実行・設定済み)

民間サービス「EDINET DB」(edinetdb.jp・無料枠100回/日)を使い、上場企業の
保有不動産(物件単位の簿価・所在地)・含み益(賃貸等不動産注記)・財務を取得します。

- **自動実行**: macOSのlaunchd(標準の予約実行)で毎日8:00に約90社ずつ調査します。
  スリープ中だった場合は起きたときに実行されます。結果はアプリの**「発掘」タブ**に
  ランキング表示され、「台帳に追加」ボタンで台帳に登録できます。
  - 止めたいとき: ターミナルで
    `launchctl unload ~/Library/LaunchAgents/com.cre-scout.edinetdb-screen.plist`
  - 実行記録: `tools/cache/auto.log`
- **今すぐ動かしたいとき**: `EDINETチェック.command` をダブルクリック
  (調査してから「発掘」タブを開きます)
- **企業を指定して深掘り**(ターミナル):
  `python3 tools/edinetdb_scan.py --company 企業名` →
  詳細データが「発掘」タブの追加ボタンに反映され、深掘りレポートと
  台帳取り込みJSON(データ管理→追記で取り込み)もできます。

### ② 公式EDINET監視(公式APIキーを取ったら使える)

`tools/edinet_check.py` は金融庁の公式EDINET APIで毎日の新着開示
(有報・半期・臨時報告書)から「減損損失」「閉鎖」「リースバック」等を検知します。
公式APIキー(無料)は https://api.edinet-fsa.go.jp/api/auth/index.aspx?mode=1 で
アカウント作成→メール認証→多要素認証を済ませると発行されます。
取得したら `tools/edinet_key_fsa.txt` として保存してください(①のキーとは別物)。
